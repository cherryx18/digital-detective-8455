### Compiler and interpreter comparison
| Point | Compiler | Interpreter |
|---|---|---|
| When translation happens | Usually before execution | During execution |
| Typical output | Translated program, often machine code | Executes instructions at runtime |
| Example | C compiler | Python interpreter |
| One advantage | Can produce an efficiently executable program | Convenient for testing and interactive execution |

### My explanation
A compiler translates source code into another form before the program runs. An interpreter executes instructions at runtime. Both help computers run programs, but they work in different ways.
