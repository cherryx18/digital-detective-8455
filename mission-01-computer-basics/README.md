
# Mission 1 — Know Your Computer

## 1. Task / objective
The objective of this mission was to understand how a computer works using the IPOS cycle and identify hardware, software and everyday computer-based systems.

## 2. Work completed
- Studied the four stages of IPOS: Input, Processing, Output and Storage.
- Listed examples of computer hardware and software.
- Classified software into operating systems, application software and utility software.
- Identified three everyday systems that use computers.

### IPOS examples
| Stage | Example |

| Processing | CPU processes the entered data |
